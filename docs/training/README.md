# Training

Learning and teaching materials for people modelling, testing, deploying and operating processes with atlas. Course planning belongs here, not in the product engineering plans under [docs/planning](../planning/README.md).

## Process development course

- [Course plan](lehrgang-prozessentwicklung.md) — learning goals, modules and course delivery phases.
- [Observation session](lehrgang-beobachtungssitzung.md) — preliminary exercise, observation protocol and evaluation criteria.
- [Facilitator guide](lehrgang-drehbuch.md) — timing, preparation and expected answers for the onboarding case.
- [Participant worksheet](lehrgang-arbeitsblatt.md) — exercises and prediction questions without the expected answers.

The course uses the deployable [onboarding example](../../examples/lehrgang/README.md). Product reference documentation is in the [handbook](../../api/web/handbuch.html).
