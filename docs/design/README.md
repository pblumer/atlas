# Design-Reviews

Entwürfe und Kritiken zur Web-Oberfläche (`api/web/`), bevor sie Code werden.

Jede Datei ist eine eigenständige HTML-Seite ohne Build-Schritt: im Browser öffnen
genügt. Die Mockups darin sind echtes Markup mit den Tokens aus
[`api/web/app.css`](../../api/web/app.css) — kein Bildformat, damit sie sich
anfassen lassen und beim Übertragen in den Editor keine Maße geraten werden müssen.

| Datei | Thema |
| --- | --- |
| [`modeler-kopfleiste-mockups.html`](modeler-kopfleiste-mockups.html) | Die Knopfgruppe rechts in der Editor-Leiste (`editor.js:496–510`): fünf Befunde am Ist-Zustand und drei Entwürfe. |

Diese Seiten dokumentieren einen Vorschlag, nicht den Stand der Oberfläche. Was
umgesetzt ist, steht im Code; was hier steht, ist zur Diskussion.
