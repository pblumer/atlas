Atlas · Reisebuchung · Kunden-Assistent

Ein Formular nach dem anderen — ohne Aufgabenliste.

Jeder Schritt ist unter der Haube ein eigener userTask der Instanz proc_reisebuchung (durable Checkpoint). Diese Seite macht daraus einen nahtlosen Assistenten: absenden → der nächste Task derselben Instanz wird sofort an dieser Stelle geladen. Welche Folgeformulare erscheinen, entscheidet die Engine (DMN + Gateways) — die kaskadierende Zielauswahl im ersten Formular dagegen der Browser (form-js).

Keine Geschäftslogik im Client. Der Assistent ruft nur: start instance · get next task + form · complete task. Die Verzweigung „welches Formular als Nächstes“ macht Atlas.

Reisebuchung—

Starte eine neue Buchung — Atlas legt eine echte Prozessinstanz an und schickt dir Schritt für Schritt die Formulare, die für deine Angaben nötig sind.
